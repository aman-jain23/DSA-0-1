# Java 0-1 🚀

My starting point for cracking SDE interviews — solving the **NeetCode 150** in Java, 
one problem at a time, with clean code and real understanding (no AI autocomplete).

## 🎯 Goal
- Build a strong DSA foundation before moving to advanced problems
- Solve all 150 NeetCode problems in Java
- Document approach, time/space complexity, and key patterns for each

## 📂 Structure
Solutions are organized by topic (Arrays, Strings, Two Pointers, Linked Lists, 
Trees, Graphs, DP, etc.) to make pattern recognition easier during review.
